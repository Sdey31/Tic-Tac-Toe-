# 🎮 Tic Tac Toe Game

A simple, interactive, and fun **Tic Tac Toe** game built using HTML, CSS, and JavaScript. Challenge your friends and enjoy the classic two-player game with a clean and responsive interface!

## 🌐 Live Demo

🚀 **Play Here:** https://tic-tac-toe-theta-seven-22.vercel.app/

## ✨ Features

- 🎯 Two-player gameplay (X and O).
- 🎨 Clean and user-friendly interface.
- ⚡ Interactive game board.
- 🏆 Automatic winner detection.
- 🤝 Detects draw conditions.
- 🔄 Restart option to play again.

## 🛠️ Technologies Used

- **HTML5** – Structure of the game.
- **CSS3** – Styling and layout.
- **JavaScript** – Game logic and interactivity.

Follow these steps to run the project locally.

1. Clone the repository:

   ```bash
   https://github.com/Sdey31/Tic-Tac-Toe-.git
   ```

2. Navigate to the project folder:

   ```bash
   cd https://github.com/Sdey31/Tic-Tac-Toe-
   ```

3. Open `index.html` in your browser.

## 🎮 How to Play

1. The game starts with Player O.
2. Players take turns marking an empty cell.
3. The first player to get three marks in a row, column, or diagonal wins.
4. If all cells are filled without a winner, the game ends in a draw.
5. Restart the game and play again!
